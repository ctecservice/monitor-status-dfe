Perguntas frequentes

Sobre o site

O que é este monitor?

É um painel público e gratuito que exibe o status dos serviços de emissão de documentos fiscais eletrônicos (DF-e) das SEFAZ de cada estado, consultando uma API e apresentando o resultado em uma grade simples: Operacional (verde), Instável (âmbar), Indisponível (vermelho) e Sem dados (cinza).

De quanto em quanto tempo os dados são atualizados?

As leituras são feitas por ciclo de coleta (por padrão, a cada 5 minutos) e o painel se renova sozinho a cada 60 segundos, sem precisar recarregar a página.

O que significa cada estado?

Operacional: o serviço respondeu normalmente. Instável: respondeu com restrição ou lentidão (cStat 108). Indisponível: o serviço está fora do ar (cStat 109). Sem dados: a fonte não respondeu (falha de rede, API ou certificado) ou ainda não há coleta para aquela combinação.

O que é o uptime de 24 horas?

É o percentual de coletas com estado operacional nas últimas 24 horas. Ele mede a estabilidade do serviço naquele período, não o tempo que o serviço existe.

Por que vejo um aviso de 'fonte indisponível' ou uma verificação anti-robô?

Para proteger o serviço contra abuso automatizado, aplicamos limites de acesso por endereço IP e, opcionalmente, uma verificação anti-robô (Cloudflare Turnstile). Usuários normais raramente percebem; bots são bloqueados.

Sobre o projeto open-source

Este projeto é open-source?

Sim. O código é aberto sob licença MIT e está no GitHub: github.com/ctecservice/monitor-status-dfe. Você pode usar, estudar, modificar e hospedar sua própria cópia.

Posso hospedar o meu próprio monitor?

Sim. O projeto foi feito para isso: funciona em uma VPS simples ou container, sem depender de nginx, e as configurações ficam em arquivos locais (config.json e .env).

O monitor só funciona com a API da DadosJah?

Não. A integração com a API de consulta é modular (chamamos de "motores"): cada API fica em um arquivo próprio e pode ser adicionada ou removida facilmente.

Como posso contribuir?

Com código, correções, traduções ou reportando problemas pelo GitHub. Pull requests são bem-vindos, seguindo as regras descritas no repositório.

Quem desenvolve e mantém o projeto?

O projeto é desenvolvido e mantido pela CTEC.

Sobre a DadosJah

O que é a DadosJah?

A DadosJah é a plataforma que fornece a API usada como fonte das consultas deste monitor. Saiba mais em dadosjah.com.br.

Os dados exibidos vêm diretamente das SEFAZ?

A DadosJah consulta os serviços oficiais das SEFAZ e expõe o resultado em uma API. Este monitor consome essa API e organiza o histórico e a apresentação.

Sobre a SEFAZ

O que é cStat?

É o código de status retornado pelos serviços das SEFAZ. De forma simplificada: 107 = serviço operacional, 108 = instável, 109 = indisponível.

A SEFAZ caiu — o que eu faço?

Não é preciso fazer nada imediato: os serviços fiscais costumam se restabelecer em pouco tempo e a SEFAZ costuma prorrogar prazos em indisponibilidades prolongadas. Em caso de dúvida fiscal, consulte os canais oficiais da SEFAZ do seu estado.

Este site é um canal oficial da SEFAZ?

Não. Este é um painel informativo independente, mantido pela comunidade. Para informações oficiais, consulte os portais das SEFAZ e da Receita Federal.
